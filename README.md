## 使用方式

### 方法一：直接打开
1. 找到 `stock_dashboard.html` 文件
2. 双击打开或右键选择"用浏览器打开"
3. 或在浏览器地址栏输入文件路径

### 方法二：本地服务器（推荐）
1. 在项目目录打开命令行
2. 运行：`python -m http.server 8000`（需要Python）
3. 打开浏览器访问：`http://localhost:8000/stock_dashboard.html`

### 方法三：VS Code Live Server
1. 在VS Code中安装"Live Server"扩展
2. 右键点击 `stock_dashboard.html`
3. 选择"Open with Live Server"

### 公网发布
这是一个纯前端页面，可以上传到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel Static Hosting，让任何人通过 HTTPS 地址访问。发布前请将 `stock_dashboard.html` 设置为站点首页，或直接分享该文件路径。

当前页面调用公开行情接口，没有内置密钥。若后续接入 TuShare 等需要令牌的数据源，必须增加服务端代理：浏览器只访问自己的 `/api`，服务端保存令牌、校验日期参数、限制请求频率，并设置 HTTPS、安全响应头和日志脱敏。不要把令牌写入 HTML、JavaScript 或仓库。

静态托管只能保护页面本身，不能解决第三方接口限流和跨域策略；要提供稳定的公共服务，建议使用带 API 代理的部署方案。

## 使用说明

### 1. 查看涨停股票
- 打开网站后，默认显示今日涨停的股票
- 左侧列表展示所有涨停股票
- 点击任意股票可查看详细数据

### 2. 切换日期
- 使用日期选择器选择其他日期
- 系统会自动加载该日期的涨停数据
- 最多可查询历史数据

### 3. 查看分时图
- 在"切换图表"下拉框选择"分时图"
- 显示当日9:30-15:00的价格走势
- 鼠标悬停可查看具体数值

### 4. 查看K线图
- 选择"日K线"、"周K线"或"月K线"
- 显示蜡烛图格式的走势
- 红色表示上升，绿色表示下降

### 5. 了解股票信息
右侧面板显示的信息：
- **当前价**：股票现价
- **涨幅**：今日涨幅百分比
- **连续涨停**：连续多少个交易日涨停（几板）
- **成交量**：当日成交量

## 数据源

页面使用东方财富公开行情接口读取指定日期的涨停池、成交量和连板统计，使用腾讯公开行情接口读取分时和历史 K 线，不再生成模拟价格或成交量。

## 技术栈

- **前端框架**：HTML5 + CSS3 + JavaScript
- **图表库**：ECharts 5.4.3（开源、功能强大）
- **数据接口**：东方财富公开行情接口

## 常见问题

**Q: 如何添加真实数据？**
A: 修改 `script.js` 中的 `fetchLimitUpStocks()` 函数，调用真实的API接口。

**Q: 为什么图表不显示？**
A: 确保网络连接正常，ECharts库需要从CDN加载。

**Q: 如何自动刷新数据？**
A: 取消注释 `script.js` 末尾的定时刷新代码。

**Q: 可以在手机上使用吗？**
A: 可以，但页面在大屏幕上体验最佳。
